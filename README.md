# Movie Rental Management System

A full-stack Movie Rental Management System designed to allow customers to browse movies, rent movies, manage their wallets, and track rental transactions.

## Project Objectives

- Customer registration and authentication.
- Movie browsing and rental management.
- Customer wallet and transaction history.
- Payment integration with OPay, Paystack, and Monnify.
- Administrative management of users, movies, and transactions.
- Responsive web, mobile, and admin applications.

## Technology Stack

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication
- Joi Validation

### Frontend
- React
- React Native

### Development Tools
- Visual Studio Code
- Git and GitHub
- Postman
- Swagger
